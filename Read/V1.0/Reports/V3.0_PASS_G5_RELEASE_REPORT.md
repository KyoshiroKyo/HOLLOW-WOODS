## 4. HƯỚNG DẪN KHỞI CHẠY & BÀN GIAO SẢN PHẨM

1. **Chạy kiểm tra QA tự động bất kỳ lúc nào:**
   ```powershell
   node Read/V3.0/verify_v3_release.mjs
   ```
2. **Kiểm tra biên dịch Type-checking:**
   ```powershell
   npx tsc --noEmit
   ```
3. **Đóng gói phát hành bản mới:**
   ```powershell
   npm run build
   ```
4. **Trải nghiệm trên trình duyệt cục bộ:**
   - Mở file `dist/index.html` thông qua bất kỳ Web Server tĩnh nào (Live Server, VSCode Static Extension, hoặc http-server).
