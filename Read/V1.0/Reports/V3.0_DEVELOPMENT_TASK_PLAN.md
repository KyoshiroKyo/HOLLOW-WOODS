## 1. TỔNG QUAN KIẾN TRÚC DỰ ÁN

### 1.1 Tech Stack

| Thành phần | Công nghệ | Phiên bản |
|---|---|---|
| Ngôn ngữ | TypeScript | 5.x (strict mode) |
| Game Engine | Phaser 4 | Latest |
| Bundler | Vite | 5.x |
| Dữ liệu | JSON | — |
| Map Editor | Tiled | JSON export |
| Nền tảng phát hành | P2Game | Web |

### 1.2 Quy Ước Chung

- **Độ phân giải ảo:** 640×360 px
- **Kích thước tile:** 16×16 px (native)
- **Scaling:** Nearest-neighbor, integer scaling (`image-rendering: pixelated`)
- **Hiển thị:** 2× tại 1280×720, 3× tại 1920×1080
- **Cấu trúc file:** Mỗi class/system một file riêng biệt
- **Naming:** PascalCase cho class, camelCase cho biến/method, UPPER_SNAKE cho hằng số
- **Export:** Named export (không dùng default export)

## 2. PASS G1 – NỀN TẢNG (Foundation)

Thiết lập nền tảng kỹ thuật hoàn chỉnh: khởi tạo dự án, cấu hình Phaser 4, hiển thị nhân vật Satyr di chuyển trên tilemap với camera follow và HUD cơ bản.

6. `TilemapManager.ts` → `CameraSystem.ts` (thế giới + camera)
7. `GameScene.ts` (kết nối tất cả)
