# 04B2 · Ảnh và log runtime

Ảnh trước dùng production 04B1, ảnh sau dùng production 04B2 tại runtime `d1e1adf`. Capture đặt cùng tọa độ, zoom 2,2× và mốc thời gian ngày/đêm. Hai ảnh cận nhà rèn dùng tâm camera đặt riêng để thấy mái và tường; ảnh đi bộ vẫn dùng camera gameplay. Ảnh F9 đến từ hai build QA.
