   - Đầy đủ 12 phân hệ: `animation`, `audio`, `config`, `data`, `entities`, `scenes`, `state`, `systems`, `types`, `ui`, `utils`, `world`.
   - Biên dịch TypeScript đạt chuẩn tuyệt đối: `0 errors` (`npx tsc --noEmit`).

2. **`public/assets/` (Tài nguyên Runtime hoàn chỉnh):**

### 3. HƯỚNG DẪN ĐỒNG ĐỘI TIẾP TỤC DỰ ÁN

```bash
# 1. Clone dự án về máy
git clone https://github.com/KyoshiroKyo/HOLLOW-WOODS.git

# 2. Di chuyển vào thư mục dự án
cd HOLLOW-WOODS

# 3. Cài đặt dependencies
npm install

# 4. Chạy game ở chế độ dev
npm run dev

# 5. Kiểm tra chất lượng code & build
npx tsc --noEmit
npm run build
node scripts/verify_v3_release.mjs
```
