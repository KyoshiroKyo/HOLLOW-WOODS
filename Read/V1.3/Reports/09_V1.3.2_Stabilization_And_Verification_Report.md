## 6. NÂNG CẤP HỆ THỐNG ÂM THANH HYBRID SFX & TRIỆT TIÊU LỖI CHÓI TAI (C4-132-10)

### 6.1. Nguyên nhân gốc rễ tiếng "rất lạ, rất khó chịu, điếc lỗ tai"
Qua kiểm tra chuyên sâu mã nguồn Web Audio API trong `src/audio/AudioManager.ts`:
